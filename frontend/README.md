# Hotel Booking Frontend

React and Vite frontend for the Hotel Booking Management System.

## Setup

```bash
npm install
npm run dev
```

The app uses this API base URL when no environment variable is set:

```text
http://localhost:8080/api
```

To point the frontend at another backend, set:

```text
VITE_API_BASE_URL=https://your-backend.example.com/api
```

## Checks

```bash
npm run lint
npm run build
```
